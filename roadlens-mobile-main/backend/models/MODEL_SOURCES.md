# Model sources

- Road-distress generalist: https://huggingface.co/vinothvikas1987/pothole-detection-yolov8
- Pothole specialist: https://huggingface.co/peterhdd/pothole-detection-yolov8

Downloaded on 24 August 2026. The accompanying model cards are preserved in this directory.

Both ONNX files contain Ultralytics metadata declaring AGPL-3.0. The generalist repository page separately labels its repository Apache-2.0. Treat the embedded metadata as the conservative licensing signal and obtain legal review before commercial distribution.

The checked-in clean-road fixture was selected from the public RDD2022-based test-image collection at https://github.com/sivakanth1/Detecting_Road_Damage solely for controlled validation. Refer to the dataset/repository licensing before redistributing that fixture beyond this evaluation bundle.
